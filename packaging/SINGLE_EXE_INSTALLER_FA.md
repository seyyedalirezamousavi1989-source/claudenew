# سیاست نصب LocalChat 2.0

هدف انتشار، یک فایل واحد `LocalChat-Setup-2.0.0.exe` است؛ نه نسخه Portable.

- فایل Setup تمام فایل‌های خود برنامه را درون خود دارد.
- PyInstaller runtime پایتون و کتابخانه‌های موردنیاز برنامه را داخل payload قرار می‌دهد؛ رایانه مقصد به Python نیاز ندارد.
- Setup در صورت نبودن، Microsoft Visual C++ Redistributable x64 و Microsoft Edge WebView2 Runtime را از لینک‌های رسمی مایکروسافت دانلود و نصب می‌کند.
- نصب Ollama، دانلود مدل‌های زبانی/بینایی، مدل‌های گفتار، موتورهای STT/TTS و افزونه‌های اختیاری درون برنامه و با انتخاب کاربر انجام می‌شود؛ این فایل‌ها در Setup پایه قرار نمی‌گیرند.
- اتصال اینترنت برای دریافت پیش‌نیازهای مفقود در زمان نصب لازم است.
- برنامه و فایل‌های کاربر در مسیرهای جداگانه نگهداری شوند تا حذف برنامه مکالمات و تنظیمات را پاک نکند.
