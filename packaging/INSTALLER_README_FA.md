# راهنمای ساخت نصب‌کننده تک‌فایلی LocalChat 2.0

## خروجی موردنظر

خروجی قابل انتشار فقط این فایل است:

`build\\installer\\LocalChat-Setup-2.0.0.exe`

این فایل یک نصب‌کننده Windows x64 است؛ Portable ZIP نیست. فایل Setup شامل تمام payload خود LocalChat و runtime پایتونِ بسته‌بندی‌شده توسط PyInstaller است. روی رایانه مقصد نصب Python، pip، PyInstaller یا Inno Setup لازم نیست.

## پیش‌نیازهای رایانه سازنده (فقط برای ساخت)

- Windows 10/11 x64
- Python 3.10 تا 3.12
- نصب Inno Setup 7 یا 6 روی رایانه سازنده؛ نسخه 7.1.1 x64 نیز پشتیبانی می‌شود و اسکریپت ابتدا آن را شناسایی می‌کند.
- دسترسی اینترنت برای نصب وابستگی‌های build

## ساخت

`build_installer.bat` را اجرا کنید. ابتدا تست‌های regression اجرا می‌شوند. اگر تستی fail شود، ساخت متوقف می‌شود. سپس PyInstaller پوشه payload را می‌سازد. اگر Inno Setup 6 روی سیستم سازنده نصب نباشد، اسکریپت نسخه رسمی 6.7.4 را از سایت ناشر دانلود و در محدوده کاربر نصب می‌کند؛ سپس آن را برای ساخت یک Setup.exe واحد به کار می‌برد.

## پیش‌نیازهای رایانه مقصد

- Windows 10/11 x64
- اتصال اینترنت در زمان نصب، اگر Microsoft Visual C++ Redistributable یا WebView2 Runtime از قبل نصب نباشد.
- Setup در صورت نیاز این دو runtime رسمی مایکروسافت را دانلود و نصب می‌کند.
- Python برای کاربر نهایی لازم نیست؛ runtime پایتون داخل payload برنامه است. Inno Setup نیز فقط ابزار ساخت است و روی رایانه مقصد نصب نمی‌شود.

## مواردی که پس از نصب از داخل LocalChat دریافت می‌شوند

Ollama، مدل‌های زبانی، مدل‌های بینایی، مدل‌ها و موتورهای گفتار (STT/TTS)، بسته‌های صوتی و ارائه‌دهندگان اختیاری نباید داخل Setup اجباری و حجیم شوند. این موارد باید از بخش مدیریت مدل‌ها/قابلیت‌های داخل خود LocalChat و بر اساس انتخاب کاربر دانلود و نصب شوند. برای مدل‌ها فضای دیسک و VRAM کافی در نظر گرفته شود.

## خطای قبلی PyInstaller

در نسخه قبلی، PyInstaller تلاش می‌کرد منابع اختیاری `lxml/isoschematron` را جمع‌آوری کند، در حالی که LocalChat از `xml.etree.ElementTree` استاندارد پایتون استفاده می‌کند و به lxml وابسته نیست. lxml در spec از جمع‌آوری خارج شده است. همچنین مسیر ورودی Inno Setup با خروجی واقعی PyInstaller هماهنگ شد (`build\\payload\\LocalChat`).

## نکته انتشار

پس از ساخت، Setup را روی یک ماشین تمیز Windows 10/11 x64 که Python ندارد آزمایش کنید. این مرحله باید نصب runtimeها، اجرای اولین‌بار، اتصال به Ollama و دانلود مدل از داخل برنامه را پوشش دهد. تست‌های Linux یا اجرای تست‌های واحد به‌تنهایی تأیید نصب Windows نیستند.
