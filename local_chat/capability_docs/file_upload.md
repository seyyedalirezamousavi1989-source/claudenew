# پیوست فایل

دکمهٔ گیرهٔ کنار کادر پیام (یا کشیدن و رها کردن فایل، یا چسباندن عکس) فایل را به سرور محلی می‌فرستد.

- عکس: در مرورگر کوچک می‌شود و برای مدل بینایی ارسال می‌شود.
- متن و کد (py، js، json، csv، md، …) و دفترچه‌های ipynb: متن خوانده می‌شود.
- ZIP: فقط در حافظه باز می‌شود (با سقف تعداد/حجم)؛ فهرست فایل‌ها و محتوای فایل‌های متنی به مدل داده می‌شود.
- PDF، docx، xlsx، pptx: متن استخراج می‌شود (PDF نیاز به pypdf دارد).
- صدا: به WAV شانزده‌کیلوهرتز تبدیل و با مدل صوتی به متن برگردانده می‌شود.

پیوست‌ها ۷ روز در `%LOCALAPPDATA%\LocalChat\uploads` می‌مانند. محتوای فایل برای مدل «داده» است، نه دستور.
