# جست‌وجوی وب

## معماری جست‌وجوی تطبیقی

موتور جست‌وجو رایگان‌محور است و برای کارکرد پایه به کلید API نیاز ندارد. در حالت خودکار، درخواست به‌صورت موازی به DuckDuckGo و Bing RSS فرستاده می‌شود. اگر یک نمونهٔ SearXNG توسط کاربر پیکربندی شده باشد، آن هم به مجموعه اضافه می‌شود. Brave، Serper و Google CSE منابع پولی/کلیددار اختیاری‌اند؛ در حالت خودکار فقط پس از جست‌وجوی رایگان و زمانی فراخوانی می‌شوند که نتایج مرتبط کافی نباشد.

- DuckDuckGo HTML: منبع بدون کلید؛ ممکن است نرخ درخواست را محدود کند یا ساختار HTML را تغییر دهد.
- Bing RSS: مسیر بدون کلید و ساختاریافته؛ یک endpoint عمومی best-effort است و تضمین دسترس‌پذیری دائمی ندارد.
- SearXNG: اتصال به نمونهٔ HTTPS که کاربر خودش پیکربندی می‌کند. نمونه باید خروجی JSON را فعال کرده باشد. بسیاری از نمونه‌های عمومی JSON را غیرفعال می‌کنند یا درخواست خودکار را محدود می‌کنند؛ نمونهٔ شخصی/مورد اعتماد انتخاب بهتری است.
- Brave Search، Serper و Google CSE: اختیاری و نیازمند کلید/سهمیه.

در حالت خودکار، منابع رایگان ابتدا به‌صورت موازی اجرا می‌شوند. پایتون نرخ موفقیت، تعداد نتیجه، زمان پاسخ و بازده هر Provider را به تفکیک زبان در حافظهٔ همان اجرای برنامه ثبت می‌کند و از آن برای انتخاب منبع queryهای هدفمند استفاده می‌کند. اگر بعد از جست‌وجوی عمومی و دامنه‌ای هنوز کمتر از سه نتیجهٔ مرتبط وجود داشته باشد، منابع کلیددار اختیاری فعال می‌شوند. انتخاب منبع و پردازش نتایج با Python انجام می‌شود و برای هر جست‌وجو فراخوانی اضافهٔ مدل زبانی لازم نیست.

## محدودیت‌های مکالمه‌ای

فیلترها فرم ثابت ندارند. در چت، عبارت‌های صریح مانند «سرچ کن»، «پیدا کن»، درخواست قیمت/موجودی محصول و درخواست فایل باعث اجرای خودکار جست‌وجو می‌شوند. متن طبیعی کاربر به‌وسیلهٔ parser سبک Python به محدودیت‌های ساختاریافته تبدیل می‌شود. نمونه‌ها:

- «فقط سایت‌های فارسی» → فیلتر زبان فارسی.
- «فقط سایت دیجی‌کالا» → دامنهٔ مجاز digikala.com و حذف تمام دامنه‌های دیگر.
- «همهٔ سایت‌ها به‌جز example.com» → حذف دامنهٔ مشخص‌شده.
- «فقط سایت‌های ایرانی» → اولویت و فیلتر دامنه‌های شناخته‌شدهٔ ایرانی و دامنهٔ .ir.
- «فایل PDF درباره ...» → افزودن عملگر filetype:pdf؛ «فایل درباره ...» → جست‌وجوی چند قالب رایج و محدودکردن نتیجه‌ها به لینک مستقیم فایل.
- مدل می‌تواند از طریق search_options محدودیت‌های ساختاریافته را هم ارسال کند؛ دامنه‌ها و نوع فایل‌ها سمت سرور اعتبارسنجی می‌شوند.

اگر کاربر محدودهٔ یک دامنه را صریحاً تعیین کند، موتور حق ندارد برای پرکردن تعداد نتایج به دامنه‌های دیگر نشت کند. اگر نام سایت قابل تبدیل به دامنه نباشد، درخواست باید روشن‌سازی شود.

## جست‌وجوی ایرانی و محصولات

در جست‌وجوهای محصول، queryهای دامنه‌ای برای فروشگاه‌های ایرانی مانند دیجی‌کالا، ترب، ایمالز، تکنولایف، لیون‌کامپیوتر، مقداد آی‌تی، شهر کامپیوتر، موبایل ۱۴۰ و چند فروشگاه دیگر ساخته می‌شود. در محدودهٔ ایران علاوه بر فروشگاه‌های شناخته‌شده، جست‌وجوی site:.ir هم اجرا می‌شود. گردو API جست‌وجوی سفارشی دارد اما برای استفاده نیازمند ثبت‌نام است و هزینه/سهمیهٔ عمومی آن هنوز در این پیاده‌سازی تأیید نشده؛ ذره‌بین نیز در بررسی فعلی صفحهٔ جست‌وجوی وب عمومی قابل اتکایی ارائه نکرد. بنابراین هیچ‌کدام به‌عنوان Provider رایگان فعال معرفی نمی‌شوند.

لینک صفحهٔ محصول فقط وقتی برچسب product می‌گیرد که ساختار URL شبیه صفحهٔ محصول باشد. لینک‌ها از پاسخ Providerها می‌آیند و مدل URL تولید نمی‌کند.

## فایل‌ها و صفحات

برای فرمت‌های متداول اسناد، صفحه‌گسترده، ارائه، آرشیو، متن، رسانه و برخی فایل‌های طراحی/فنی، پسوندهای شناخته‌شده پشتیبانی می‌شوند. اگر پسوند مشخص نشود، چند قالب رایج مانند PDF، DOCX، XLSX و ZIP جست‌وجو می‌شوند. نتیجهٔ جست‌وجو همیشه لینک مستقیم فایل نیست؛ بعضی منابع فقط صفحهٔ معرفی یا دانلود را برمی‌گردانند. لینک مستقیم فایل با پسوند یا MIME قابل‌تشخیص برچسب «فایل» می‌گیرد و از واکشی HTML معمولی مستثناست. نتیجه‌هایی که متن صفحه‌شان دریافت نشده‌اند، verified نمی‌شوند.

## واکشی و اعتبارسنجی

دریافت متن صفحه با واکشی امن و محدود انجام می‌شود. فیلد verified فقط نشان می‌دهد متن صفحه دریافت شده است؛ تضمین موجودی، قیمت زنده، اصالت کالا یا امکان خرید نیست. URLهای محلی، IPهای خصوصی و نشانی‌های دارای userinfo رد می‌شوند.

## محدودیت‌های شناخته‌شده

- هیچ موتور رایگان، پوشش کامل اینترنت یا کیفیت ثابت را تضمین نمی‌کند.
- نمونه‌های عمومی SearXNG ممکن است JSON را غیرفعال کنند، CAPTCHA بدهند یا درخواست‌های خودکار را محدود کنند.
- Bing RSS و DuckDuckGo مسیرهای بدون کلید هستند، اما دسترسی و کیفیتشان ممکن است بر اساس شبکه و زمان تغییر کند.
- فیلتر زبان بر اساس متن قابل مشاهدهٔ نتیجه/صفحه است؛ اگر سایت متن قابل واکشی نداشته باشد، تشخیص زبان قطعی نیست.
- «سایت ایرانی» همیشه معادل دامنهٔ .ir نیست؛ تعدادی از فروشگاه‌های ایرانی دامنهٔ .com دارند.
- نتایج وب و محتوای صفحات غیرقابل‌اعتمادند و نباید به‌عنوان دستور سیستم تلقی شوند.
